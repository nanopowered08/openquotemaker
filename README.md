# OpenQuoteMaker

Yes, least self-deprecating name you've seen in awhile.

This quote maker has some inspiration [from this discord bot's](https://greed.best) quote generator.

## How do I use it?

Well,

```bash
pip install pillow
```

Some of you guys are on termux so-

```bash
pkg i tur-repo x11-repo
pkg i python-pillow
```

Then the syntax is:

```bash
python app.py (image) "quote" "display name" "username"
```

For example...

```bash
python app.py finch.webp "Please, I'm a professional." "The Freelancer" "Finch"
```
